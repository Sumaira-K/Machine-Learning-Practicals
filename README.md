# Machine Learning & Data Science Experiments

A collection of Jupyter notebook-based machine learning experiments and data science projects. This repository contains practical implementations of data preprocessing, exploratory data analysis, and machine learning algorithms.

## Repository Structure

### **Datasets**
- `titanic_data.csv` - Titanic dataset for EDA and predictive modeling
- `AB_NYC_2019.csv` - Airbnb NYC 2019 dataset for analysis

### **Experiments**

#### **Python Fundamentals**
- `Exp01(Demonstrating various list operations).ipynb` - List manipulation and operations
- `Exp02(Demonstrating various dictionary operations).ipynb` - Dictionary manipulation techniques

#### **Data Preprocessing**
- `Exp03(Data Preprocessing on Titanic Dataset).ipynb` - Data cleaning, handling missing values, feature engineering on Titanic dataset

#### **Exploratory Data Analysis (EDA)**
- `Exp05(EDA on Titanic Dataset).ipynb` - Statistical analysis, visualizations, and insights from Titanic dataset

#### **Machine Learning Models**
- `Exp06.1(Linear Regression).ipynb` - Linear regression implementation and analysis
- `Exp06.2(Logistic Regression).ipynb` - Logistic regression for classification problems

#### **Data Generation**
- `Exp04(Random Data Generation).ipynb` - Generating synthetic datasets and random data manipulation

#### **Evaluation**
- `Lab_Evaluation.ipynb` - Comprehensive evaluation of all experiments and results

## Learning Objectives

This repository covers:
- Python basics (Lists, Dictionaries)
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization techniques
- Linear Regression modeling
- Logistic Regression for classification
- Statistical analysis
- Feature engineering
- Model evaluation metrics

## Getting Started

### Prerequisites
- Python 3.7 or higher
- Jupyter Notebook or JupyterLab
- Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn

## Dataset Information

### Titanic Dataset
- Passenger information including survival status
- Features: Age, Sex, Class, Fare, Embark Port, etc.
- Used for: Preprocessing, EDA, and predictive modeling
  
### Airbnb NYC 2019 Dataset
- Airbnb listing information for New York City
- Features: Price, room type, location, reviews, etc.
- Used for: Data analysis and insights
